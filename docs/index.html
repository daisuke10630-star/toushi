選び方：過去6か月の上昇率が高い順（10銘柄に分散）

移動平均・RSI・ボリンジャーバンドを使う選び方は、10年検証で すべて単純保有に負けました。唯一勝ったのが、指標を使わず 「上がっている銘柄をそのまま買って持つ」この方法です。 ランダムに10銘柄選ぶ対照群が負けていることを確認済みで、 上昇相場だから勝てたのではありません。
